# Chessktop

Aplicación de escritorio/web para el estudio de ajedrez.

## Tecnologías

- React
- TypeScript
- Vite
- chess.js
- react-chessboard

## Estado actual

- ✅ Tablero interactivo
- ✅ Árbol de variantes
- ✅ Notas por jugada
- ✅ Biblioteca de estudios
- ✅ Gestión de carpetas
- ✅ Exportación PGN

## Próximas funcionalidades

- Importación PGN
- Motor Stockfish
- Repetición espaciada (SRS)
- Búsqueda de posiciones
